[A1] Saludo nocturno incorrecto
────────────────────────────────
  Escenario  : Saludo simple a las 20:45 (franja nocturna)
  Input      : "Hola"
  Respuesta  : "¡Buenas tardes! 🌊..."
  Esperado   : "¡Buenas noches!"

  Criterios fallidos:
    - saludo_noche : Saludo nocturno correcto
    - pregunta     : Cierra con pregunta (secundario)

  Causa raíz:
    El test inyecta la hora actual mediante:
      content.replace("{{CURRENT_DATETIME}}", "2026-03-15 20:45")

    Sin embargo, el prompt LAURA_5_3.1.md contiene en la sección 9:
      "Saludo según franja horaria basado en CURRENT_DATETIME"

    El placeholder en el prompt NO tiene dobles llaves ({{ }}), por lo
    que el replace() de Python no encuentra ninguna coincidencia y nunca
    sustituye el valor. El modelo recibe el texto literal "CURRENT_DATETIME"
    sin saber que son las 20:45, y por defecto asume horario de tarde.

  Impacto: 1 escenario fallido, 2 criterios.
